# 调研报告：Photoshop 用途分支与输入端路由（ps-mcp v0.2.0 · 2026-09-19）

> 目的：在 intake 最前面增加**第 0 步分支判定**——不同用途分支的门配置、风险面、
> 档位语义、agent 可代做边界差异大到"不先判分支就会选错门、选错档、接错活"。
> 本报告是依据；可操作的路由表蒸馏在 `references/00-task-intake.md` §0。
> 证据标注：[实测·静态]=本机装机内容直接可查（2026-09-19）；[实测]=本机 COM 探针；
> [网调]=当日在线来源（检索日期均为 2026-09-19，摘要级可信度）。

## 1. 方法

三个证据源三角定位：(a) 本机装机内容（预设目录/内置脚本/UXP 扩展/新建文档预设——
Adobe 给 27.10 配什么工具，就是它认为 PS 在干什么）；(b) Adobe 官方定位与文档（当日网调）；
(c) 本 skill 已实测的 COM 机制层可达性（哪些分支 agent 真摸得到）。分支划分以
"输入端可判定的特征 + agent 可代做边界"为准，不以教科书式功能分类为准——
路由要的是判定，不是百科。

## 2. 机器与生态证据摘要

**装机内容 [实测·静态]**：
- 内置脚本（Presets/Scripts）：Image Processor（批处理）、Export Layers To Files、
  Layer Comps To Files/PDF、Artboards To Files/PDF、ContactSheetII（联系表/缩略墙）、
  Photomerge（全景拼接）、Merge To HDR、Lens Correct、Conditional Mode Change、
  Fit Image、Load DICOM（医学影像）、Flatten All Masks 等——**批处理/切图/拼接/
  全景/HDR/医学影像的分支工具全在**；
- 预设目录：Brushes（绘画）、Actions（动作/批处理）、Video（视频）、3DLUTs（调色）、
  HDR Toning、Color Books（专色/印刷）等；
- 新建文档预设类别（Required/Default New Doc Sizes.json）：**uspaper / europaper /
  photo / web / mobile / video / iconography / artillustration / artboard** 九类
  ——Adobe 自己的分类学，与本报告分支一一对应；
- UXP 公共扩展仅 Adobe 自家三件：ccx.start（Express 入口）、uam、
  **substance-3d.viewer.ps（退役残留，见 H 分支）**；Generator 插件在 Plug-ins/（D 分支
  legacy 切图技术）；Camera Raw 组件在 Required/（A 分支）。

**官方定位与生态 [网调 2026-09-19]**：
- Adobe 官方口径：修图（retouching/合成场景/色彩）、平面设计、图像合成、插画创作，
  加上 2026 年重仓的 AI 对话式编辑（Creative Agent 内置 PS 桌面版）；
- **3D：内置 3D 引擎自 22.5（2021-08）起移除**，替代品 Substance 3D Viewer 也于
  2025-10-16 停止支持——但**本机残留其 UXP 扩展**（substance-3d.viewer.ps），
  判定为退役残留，不作为 3D 分支依据；
- **帧动画/视频时间轴仍在**（Animation 面板 frame/timeline 双模式，文档 2026-03 仍更新）；
- 生成式工具线（生成式填充/扩展、Harmonize、Generative Upscale）依赖 Adobe 云与积分。

## 4. 分支详述

### A 照片后期与修图（核心分支）

- **典型任务**：曝光/白平衡/对比度调整、色彩校正、裁剪构图、锐化、瑕疵修整（污点/
  仿制）、人像液化与肤质、产品图抠底、批量统一调色。
- **输入特征**：文件=单张照片（.jpg/.png/.tif/.psd/.cr2/.cr3/.arw 等 RAW）；用户话术
  ="修一下/调色/去瑕疵/抠图/变亮变暗/统一风格"；产物=同尺寸或裁剪后图片。
- **工具族**：调整层与调整（Curves/Levels/Hue-Sat）、Camera Raw 滤镜【△文献】、修复
  工具族、液化【△文献】、选择与蒙版。
- **机制层依赖**：调整层创建与参数【△文献，用前探一条】；选区与填充【✓实测】；
  profile 机验【✓实测】；液化类笔刷交互【✗待实测，预期弱】。
- **破坏性风险面**：直接在像素层调整（非调整层）不可逆；changeMode/changeSize 重采样；
  profile 转换偏色（静默家族）。
- **门与档位**：完整走 G0→G1→G3→G4；深度档（轻修/标准/合成级）**为本分支定义**。
- **agent 可代做边界**：参数化调整、批量统一、选区抠图、锐化降噪全可代做；"好不好看"
  的审美裁决交 G1 对比图与用户；精细手绘式修瑕（如复杂发丝）预期人工——自动工具够用
  则代做。
- **状态**：MVP 核心路径，今天全链路（建档/导出/回读）已实证。

### B 创意合成/蒙太奇

- **典型任务**：多素材拼合场景、换天/换背景、元素移植、阴影与融合、海报主体合成。
- **输入特征**：文件=多张素材 + 一张底图或画布要求；话术="把 A 放进 B/合成/拼/融合"。
- **工具族**：置入智能对象、蒙版、混合模式、Harmonize（AI 调和，2026 新）【△文献】。
- **机制层依赖**：duplicate/智能对象清单【✓实测可达】；place/置入【✗待实测】；
  蒙版创建【△文献】。
- **破坏性风险面**：智能对象缩放栅格化静默损质（规划书风险 4）；跨文档 profile 不一致
  （02 分册 §5）；多素材=多份"用户原图"同时在场——**源文件只读纪律压力最大**的分支。
- **门与档位**：全门走；档位默认"合成级"；**G1 对比图义务最重**（合成方向错了返工
  最贵）。
- **agent 可代做边界**：结构搭建（置入/缩放/蒙版/顺序）可代做；融合质感与"真不真"
  交用户裁决；AI 融合（Harmonize）见 G 分支。
- **状态**：承接，工艺等实战回填（03 册）。

### C 平面设计/版式物料

- **典型任务**：海报/易拉宝/社媒图、画板多尺寸套版、文字排版、Logo 位换装、印刷物料
  （CMYK/出血/专色）。
- **输入特征**：文件=.psd 模板（多文字层/智能对象占位）或从零建画布；话术="做一张/
  排一版/出全套尺寸/改文案换图"；产物=多尺寸/多变体成套交付。
- **工具族**：文字图层与字符/段落样式、形状与矢量、画板（artboard）、智能对象替换
  （模板换装）、Color Books 专色。
- **机制层依赖**：**文字内容与字体机读【✗待实测 F-10：textItem 字段】**——C 分支 G3
  机验的刚需；画板 API【✗待实测（Artboards To Files 内置脚本可作后备路径）】；
  智能对象替换【✗待实测】；CMYK changeMode【△文献，破坏性先快照】。
- **破坏性风险面**：文字层编辑破坏排版历史（用户的排版是不可再生资产，等同手绘图层）；
  印刷色彩空间转换不可逆。
- **门与档位**：全门走；G3 判据增加"文字清单与字体清单对账"（F-10 落地后）；
  档位语义=变体数与改版深度（intake 时按分支声明，见 §5）。
- **agent 可代做边界**：模板换装/多尺寸套裁/文案替换可代做；版式审美与字体搭配
  交用户；印刷前检查清单（出血/黑版/总墨量）【△文献】需机验补齐前只做提示不做保证。
- **状态**：承接，但**文字机读落地前限结构操作**（不承诺排版级编辑）。

### D UI/网页资产切图

- **典型任务**：从设计稿切出图标/插画资产、多倍率导出（@1x/@2x/@3x）、WebP/PNG/SVG
  导出、命名规范化批量重导。
- **输入特征**：文件=.psd 设计稿（图层命名即资产名约定）；话术="切图/导出资产/
  出 @2x/这套图要三种尺寸"；产物=一批命名规范的小图。
- **工具族**：Export As【△文献：菜单级，脚本可达性待探】、Generator legacy（图层名
  后缀自动导出）【△文献】、Export Layers To Files 内置脚本【实测·静态在装】、
  exportDocument/saveAs【✓实测 saveAs/PNG】。
- **机制层依赖**：本分支几乎全在已实证区（saveAs/图层树/批量遍历）；尺寸机验天然。
- **破坏性风险面**：全家族最低——只读源稿+纯导出；注意导出白名单（不覆盖旧资产包）。
- **门与档位**：G0（图层清单即资产清单）→ G3（尺寸/格式/命名对账）→ G4（抽检实看
  ——数量大时抽检+清单全核，抽样规则进 report）；G1 可轻量化为"首件确认"。
- **agent 可代做边界**：全可代做，是脚本主场；唯一人工点=资产边界取舍（某效果要不要
  扁平化导出）。
- **状态**：承接，MVP 后第一批实战候选。

### E 批处理/数据驱动流水线

- **典型任务**：上百张图统一调色/加水印/缩放/转格式；按变量数据集（CSV 驱动）生成
  个性化物料；把"动作"(.atn) 批量套到文件集。
- **输入特征**：文件=目录级文件集；话术="这一批都/统一处理/套模板/每张都加"。
- **工具族**：Image Processor【实测·静态在装】、动作与批处理、变量数据集【△文献】、
  直接 COM 循环（agent 原生方式）。
- **机制层依赖**：open/close/saveAs 循环【✓实测单件链路】；批量会话的进度留痕
  （每 N 张导 checkpoint 预览+断点记录进 report）【本 skill 设计，待实战】。
- **破坏性风险面**：**批量=破坏性放大器**——单件失误乘 N；"覆盖输出"诱惑最大
  （白名单+版本化铁律在此分支最高压）；长会话卡 UI（规划书风险 6）。
- **门与档位**：G0 增加文件集清单与抽样盘点；**首件走全门**（首件=试产），通过后批量
  复制同一脚本路径；每 N 件 G3 抽检+G4 抽样实看。
- **agent 可代做边界**：全可代做；但**批量首跑必须先单件试产给用户过目**（E 分支
  铁上加铁）。
- **状态**：承接（与 COM 通道同构，天然主场）。

### F 数字绘画/插画（弱匹配）

- **典型任务**：插画创作、概念图、笔刷手绘。
- **输入特征**：文件=.psd 大图层量绘画稿；话术="画一个/帮我画"。
- **工具族**：画笔引擎（Brushes 预设在装【实测·静态】）、对称/湿边等笔刷特性。
- **机制层依赖**：笔刷笔触经 COM 不可表达为"有笔意的笔画"【推测，机制上只有
  模拟坐标点击=无笔压无手感】——**机制层不匹配，不是待实测而是边界**。
- **agent 可代做边界**：**画笔笔触与手绘属于人的领域，agent 不代画**（A7 家族原则
  在本分支的落点）；可代做=画布建立/图层结构整理/配色板准备/导出/缩略墙。
- **门与档位**：用户在画时的 agent 角色=结构与文件管家，G0/G4 照走，G1 变为
  "结构确认"。
- **状态**：承接结构操作；"代画"请求一律明示边界并拒绝静默承接。

### G AI 生成/增强（Firefly 线）

- **典型任务**：生成式填充/扩展（空区补全、出图）、生成式还原、Harmonize（多素材
  AI 调和）、Generative Upscale（AI 放大）、对话式编辑（Creative Agent）。
- **输入特征**：话术="AI 补个背景/AI 扩图/放大不糊/调和一下"。
- **机制层依赖**：**脚本可达性【✗待实测 F-9】**——executeMenuCommand/batchPlay 路径
  未探；Firefly 类功能依赖登录态与生成积分【△文献】；结果不可脚本预测。
- **破坏性风险面**：生成结果直接落在像素上（先快照）；积分消耗=**有成本的操作**，
  误触发烧积分。
- **门与档位**：每次生成=一次"方案"（G1 对比图义务）；积分消耗先向用户声明并确认
  （外部成本→确认纪律）。
- **agent 可代做边界**：可代触发（F-9 落地后）+ 实看核验；"生成什么"由用户描述，
  agent 不替用户做创意决定。
- **状态**：试探性承接——F-9 实测前不承诺；对话式编辑（Adobe 自家 agent）与本 skill
  分工：它做生成，本 skill 做脚本级结构与批量化。

### H 边界分支（判定后直接路由，不展开 SOP）

- **H1 RAW 全流程**：编目/管理/批量 RAW 开发是 Lightroom 的领域；PS 只接
  Camera Raw 滤镜入口【实测·静态在装】。路由：全流程 RAW 管理不承接，指路 LR；
  单张 RAW 文件以"打开即像素化调整"按 A 分支处理。
- **H2 帧动画/视频时间轴**：功能在（Animation 面板 frame/timeline）[网调 2026-03 文档]；
  PS 不是剪辑工具。路由：GIF 帧动画导出/帧序列导出可做（限小任务）；视频剪辑任务
  **指路 davinci-mcp**（家族分工）。
- **H3 3D**：内置 3D 引擎 2021 起移除、Substance Viewer 2025-10 退役 [网调]；
  本机 substance-3d.viewer.ps UXP 扩展为**退役残留**【实测·静态】，不构成承接依据。
  路由：建模/贴图/渲染任务**指路 blender-mcp**；贴图文件（法线/高光贴图）作为普通
  图像按 A 分支处理。

| 用户话术 | 修/调/抠/去/锐化/统一 | A（素材源可能是 B/C 的底） |

### 5.2 复合任务规则

以**产物分支为主分支**、素材来源分支为辅（"给海报换产品图"=C 为主，A 的抠图为其
子步骤）；复合任务在开工消息里显式拆分声明（主分支+子步骤清单），路由只发一次。

### 5.3 歧义与确认规则

- 判不准时不猜：分支确认并入两段式第一段第一问（"这是修图还是切图/还是合成？"）；
- 判准了也要在开工消息**报分支与后果**（门配置/档位/边界），用户可当场纠正；
- 两分支同时命中时，**防护取重**（按破坏性更强的分支配门与快照纪律）。

### 5.4 路由后果映射（判了分支改变什么）

| 分支 | G1 强度 | 档位语义 | 快照密度 | 特别纪律 |
|---|---|---|---|---|
| A | 标准 | 轻修/标准/合成级 | 像素操作前 | profile 机验 |
| B | **最重** | 默认合成级 | 每次置入/融合前 | 多源只读压力最大 |
| C | 标准 | 变体数/改版深度 | 文字/模式转换前 | F-10 落地前限结构操作 |
