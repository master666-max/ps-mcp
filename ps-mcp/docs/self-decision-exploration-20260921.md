## 2. 自决策的边界（哪些绝不能自动）

1. **门不能被跳过**：G1 用户裁决、深度档确认——自决策可以建议，不能代替；
2. **铁律不能被"决策"绕过**：源文件只读、快照先行不是可选项；
3. **晋升标准不是模型意见**：候选→清单项=≥2 次实战（机器规则），自动化只能计数，闸在人；
4. **静默是唯一禁止项**：自决策扩大自主权的同时必须收窄静默——所有自动决策公开在决策清单里。
