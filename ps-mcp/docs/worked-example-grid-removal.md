## 过程与转折点

### v1：逐像素估 α（被否决）

方法：bg=线两侧 w+2 处像素均值 → 逐像素 α=(obs-bg)/(255-bg) → 逆解 → 两遍竖横。
**Px 实看缺位下的宣告被用户 G1 击穿**：降采样视图判"干净"，1:1 下残痕明显
（背景代理误差污染 α——细节丰富区 bg≠线下真值）。教训两条：①方法级——α 剖面
沿线恒定，应按横截面估计（v2）；②流程级——判定分辨率不足=没看（升铁律 8/D13）。

### v2：横截面 α 逆混合（G1 通过）

核心改进：α(dx) 按横截面逐偏移取**沿线中位数**（只用暗+平坦行选样），实测
α=0.500（50% 透明白），逐像素精确逆解 orig=(obs-255a)/(1-a)；背景采样距离
≥w+6；竖横两遍交点自然处理；迭代检测确认残线归零。
**Px 实看**：4 条线 × 3 段全长瓦片（前后并排）逐块过目。

### 独立验收（用户指令，M15 精神）

独立枚举+源圣域（mtime 2024-03-28 ✓）+数字核对+**独立残线机查**（p25 阈值严于
处理器）——抓到 v1485/h754 最差段有低于正常观感阈值的淡痕；1:1 最差段瓦片视觉
裁决=真实存在但轻微。**数字机查与视觉实看互补**：机查定位可疑段，视觉定轻重——
单用任何一个都会漏（机查无视觉会误报内容对比度，视觉无机查会漏淡痕）。

### 二轮精修（v3）

残差定向二次校正：同一横截面法作用于 v2 输出，测残差 α（阈值 0.004=JPEG 噪声
底，之下不动）。实测：v1485 单列(-4px) α=0.039 逆除；h754 无效列（≤噪声底）；
Px 实看前后瓦片通过。残余 p25 信号判定为内容对比度（非线痕）——**机查信号必须
经视觉裁决才能定罪**。
