# 工艺库登记册（craft-library）— ps-mcp

> 两层结构（v0.6.0）：**清单项层**（实战验证=默认打法）+ **候选层**（P1/P2 分级，
> 来源在册）。输入端路由（00 分册 §0 第 0 步，含混合用途检测）判出分支后，候选取用
> 走三级递进（L1 分层/L2 组合缓存/L3 兜底重排，见 00 分册）。

## 0. 分配与生长机制

- **条目 ID = CL-<分支码>-<两位序号>**；分支码 = 路由的 A-H + **X（跨分支：所有任务
  都读 X 节**——决策二裁决 a+c；X 审计结论=无条目够无条件铁律格，留在 X 节）；
- **清单项层**：默认打法，可偏离但须留痕；**清单项必须实战出处**（≥2 次实战支撑，
  或单次实战+官方判据互证）；禁止把候选当清单项执行；
- **候选层两级标定（0.6.0 校准，报告见 docs/craft-research/p1p2-calibration-20260919.md）**：
  **P1=核心常读**（治理指定——本地重排器对 meta 规则全 0，实证 P1 不可由重排器得分
  推导）；**P2=条件触发**（条件写在条目状态里，条件不命中不读）。重排器只建议 P2
  条件归属与 L3 顺序，人工保留否决权；
- **候选层来源**：每条注 CR-<分支>-NN 指针（原文见 docs/craft-research/）；官方级
  来源可直接登记为候选（≠清单项）；
- **争议条目**：两派并列、恒为候选、禁升清单项，引用时向用户明示"此处无社区共识"；
  **争议分流（⑬，0.8.0）**：按任务题材自动选派系（如 FS 顺序按题材分流）并在开工
  消息声明所选派系；**时效衰减（⑭，0.8.0）**：带 as-of 的条目超 6 个月自动标
  "陈旧，须现查"（数值只作预期值不变）；
- **核（视觉核验点）字段（0.7.0 起）**：条目可带"核"——该工艺生效时**看什么/多大
  分辨率/判什么/异常信号**。条目驱动的操作自动把核检查加入当任务**检查计划**（宣告
  行附实看清单）；这就是知识库对多模态能力的识别与启动：库不只存知识，还调度感知；
- **时效条目**：数值带 as-of 日期只作预期值，交付判据永远=现查当期官方规格页；
- **写入与晋升**：候选 ≥2 次实战支撑 → 升清单项（留出处）；被替代标"冻结"不删行；
  收工三问触发新候选登记（无来源出处不得登记）。

## 3. 任务型组合缓存（L2：排一次用很久）

规则：**任务型首次出现时排一次，结果写回组合缓存**；同型任务直接复用不再排（缓存的
组合若有 ≥2 次实战命中，其中的核心条目可启动晋升评估）。缓存放空了就是"还没遇到"，
不是"没有"。
