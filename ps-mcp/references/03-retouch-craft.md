# 03 修图与合成工艺（工艺层槽位）

## 本册有意接近空白

这不是遗漏，是工艺层留白原则（母框架 1c / 规划书 1c）：修图工艺（哪脏先修、瑕疵判据、
合成融合顺序、输出锐化策略、停手时机）**一条不预写**——预写的工艺是未经验证的臆测，
会制造"声称↔实作"债务。真理来源是交付质量（成图与用户裁决），不是文档。

## 生长机制（容器已立，内容等实战）

- 触发：每次真实修图任务收工三问（什么判断被证明对？什么判据该固化？什么顺序错了？）
  → 记入 docs/worked example 与台账；
- 升级条件：同一判据 **≥2 次实战支撑**才写成清单项；每条清单项必须带实战出处
  （哪次任务、什么证据）；
- 声明式偏离：未来清单按 Tier 1 不变量 / Tier 2 默认打法 / Tier 3 条件表分层，
  Tier 2/3 可偏离但须留痕——分层机制照母框架，内容一律实战长出。

## 当前唯一的最低工艺（来自治理层，非工艺层）

AGENT_ 副本上动手 + 破坏性操作前快照 + 导出回读（SKILL 铁律 2/3、04 分册）——
这条保证"错了能回退"，不保证"修得好"；"修得好"等实战教。
