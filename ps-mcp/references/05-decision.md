# 05 决策体系（自决策层）— ps-mcp v0.8.0

> 本分册回答：AI 在流程中的**自主决策**怎么做、怎么留痕、什么时候必须交给人。
> 前提（D14，用户裁决"全部干，深度融入 LLM 自决策"）：LLM 是决策引擎，
> 三路证据喂给它——**感知**（看到了什么）＋**经验库**（条目怎么说）＋**机查数据**
> （扫描出了什么）；每个决策以三元组落 report 决策清单；置信度不足自动降级为提问。

## 1. 决策三元组与置信度三档

- **三元组**：每个自主决策记 `{what: 选了什么, why: 依据, confidence: 高/中/低}`
  进 report 的 `decisions` 节。依据必须**指认证据**：视觉首察所见（哪块瓦片）、
  机查数据（哪个指标）、工艺库条目（哪个 CL-ID）、实测先例（哪次任务）——
  "我觉得"不构成依据。
- **三档规则**：
  - **高置信**（依据=本机实测或官方规格）：自动执行；
  - **中置信**（依据=权威候选/单次实战/推断）：执行但在 decisions 里标记，
    Px 实看重点盯；
  - **低置信**（依据=推测/无先例/争议未决）：**不执行——决策降级为提问**
    （进 intake 问题池，或 Px 当场停下问用户）；
- **红线（不可自决策，铁律 9）**：门的存在性（G1 用户裁决）、源文件安全、
  晋升标准（≥2 次实战）、深度档、隐私与系统状态——自决策可以**建议**，
  不能**代替**。

## 2. 感知决策：检查计划自生成（⑨⑩⑪）

- **触发**：G0 首察后（整图检查计划）、Px 每个写操作后（操作区计划）、G3 前（全长核验计划）；
- **方法**：处理区几何 ＋ 工艺条目"核"字段 → 检查计划（瓦片位置/数量/倍率）；
  `scripts/residual_scan.py` 对处理区做残差扫描 → 异常段按严重度排序 → 瓦片按序生成
  （机查定位，视觉定罪——grid 验收实证的互补关系）；
- **两级视图**：降采样导航（看全局，不判质量）→ 1:1 定点（做判定，CL-X-08）；
- **决策记录**：计划本身进 decisions（"为什么看这几块、为什么这个倍率"）。

## 3. 方法决策：去除/修复策略树（①）＋ 方法竞速（⑥）

- 首察特征**三分支**（依据=视觉首察的纹理与叠加形态）：
  - 平坦渐变区（天空/皮肤/背景）→ 填充类（内容识别/修复画笔）【△文献】；
  - **线稿、规则纹理、半透明叠加**（网格/水印/字幕条）→ **数学逆混合**（CL-A-08）；
  - 大面积语义内容（需要"无中生有"）→ 生成类【✗待实测，前置 F-9】；
- **竞速规则**：归属不确定 → 两法各跑小样（限 ~512px 区域），机查＋视觉对比择优，
  择优结论进 decisions（CL-X-07 的自动化）。

## 4. 流程决策

- **门配置降档（⑤）**：仅限路由后果表（00 §0）列明的分支默认（如 D 分支首件确认）；
  其余门一律不降；降档决定进 decisions；
- **失败路由三分类（⑦）**：Px 失败先分类再动作——**参数问题**（方向对、程度不对）
  → 调参重跑；**方法问题**（方向就不对/换工具才对）→ 换法重跑（并回填工艺库）；
  **理解问题**（目标本身存疑）→ 停下问人。判不准归哪类＝按理解问题处理；
- **交付格式（⑧）**：轻修→JPG q95＋PNG 无损主档；设计→分层 PSD＋按规格导出；
  批量→与源同格式；用途特殊（印刷/平台规格）→现查当期要求（CL-C-06）；
- **批量断点（④）**：首件计时 ×20 为存档间隔（上限 20 张一批），抽检率 5%。

## 5. 知识决策：命中计数（⑫）/ 争议分流（⑬）/ 时效衰减（⑭）

- **命中计数**：收工对账——report 引用的候选条目，命中且通过 → 计数+1
  （`scripts/hit_counter.py` 输出建议，人工落账）；达 2 次 → 提示晋升
  （**晋升闸在人**，铁律 9）；
- **争议分流**：带争议标的条目，按题材自动选派系并在开工消息声明
  （"此处无共识，我按 X 派尝试，可换向"）；
- **时效衰减**：带 as-of 的条目超过 6 个月 → 自动标"陈旧，须现查"。

## 6. 导出参数决策（②）→ 见 04 分册 §2.1；快照分级（③）→ 见 02 分册 §2.1。

## 7. 红线清单（重申，违反即停）

**门的存在性 / 源文件安全 / 晋升标准 / 深度档 / 隐私与系统状态**——
这五类只接受"建议+用户裁决"，永不自动执行。置信度不足时，决策降级为提问；
降级本身也是一条 decisions 记录（what=转为提问）。
