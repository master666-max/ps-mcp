# ps-mcp

Photoshop 桌面驱动 skill。**知识包，不是 MCP 服务器**。COM 直连 + 文件总线兜底，零依赖。

## 装

拿 `ps-mcp/` 整个目录，或解 `ps-mcp-v0.7.1.zip`。

| 路径 | 用途 |
|---|---|
| `ps-mcp/SKILL.md` | 主说明书 |
| `ps-mcp/INSTALL.md` | 装到各客户端的路径 |
| `ps-mcp/references/` | 工艺库 |
| `ps-mcp/scripts/` | 驱动脚本 |
| `ps-mcp/evals/` | 验收样例 |

## 死规矩

- 原图全程只读。所有操作在带 `AGENT_` 前缀的副本上做。
- 不可逆操作（合并图层、删除、大改）前先存中间版本。
- 每做完一步必须放大自检并与上一步对比，不许攒到完工。
- 交付三件：成品 + 左右对比图 + 检查清单。

## 已知坑

Photoshop 启动弹窗会把自动化卡死，报 `0x80080005`。网上改注册表的教程方向基本不对，按 `INSTALL.md` 处理。
