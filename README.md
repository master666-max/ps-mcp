# ps-mcp — 让 AI 助手安全地用你的 Photoshop

一句话：放在 AI 助手手边的一套 **Photoshop 操作手册 + 工具包**。它能帮 AI 帮你修图、
抠图、切图、批量处理，同时保住两条底线——

- **不会碰坏你的原图**（所有改动都在副本上，改前自动存档）
- **不会嘴上说"修好了"其实没细看**（每一步都要放大检查、给你对比图）

不装插件、不改 Photoshop 设置、不依赖任何第三方软件。Windows 自带的 PowerShell 就能跑。

---

## 它替你解决的三个真问题

**1️⃣ Photoshop 启动时的弹窗会把自动化卡死**
Photoshop 启动时经常弹警告窗（最常见的是"暂存盘空间不足"）。只要它开着，任何程序都
连不上 Photoshop，还会报一个很难懂的错（`0x80080005`）——网上教你改注册表、用管理员
权限的教程基本都是错的方向。这套工具会**自动发现并处理这类弹窗**，然后正常连上。
（这是反复实测确认的原因，不是猜测。）

**2️⃣ AI 修图最容易出的事故：改坏原图**
这里的核心规矩是：**你的文件只读**。所有改动发生在带 `AGENT_` 前缀的副本文件上
（一眼就能认出哪个是 AI 的工作文件）；每次做不可逆的操作之前，自动先存一个中间版本，
随时能退回去；导出只写到你确认过的位置，绝不覆盖已有文件。

**3️⃣ AI 说"修好了"，但它真的仔细看了吗？**
很多 AI 修图的问题不是技术差，是**它没认真看**。这套工具把"看"写成了硬要求：
每做一步都要放大自检、发现不对当场修正；完工必须给你对比图和局部特写；交付消息里
要列出它检查过哪些画面——"没看过的不许说好"。

## 特点

| 特点 | 说明 |
|---|---|
| **连接够稳** | 自动处理 Photoshop 启动弹窗；连不上时给明确原因和处置步骤，不瞎试 |
| **原图安全** | 原文件只读；改动只在副本；不可逆操作前自动存档；导出从不覆盖已有文件 |
| **全程看得见** | AI 每步放大自检 + 前后对比；完工给左右对照图和局部特写，你自己验 |
| **先看再动** | 开工先看清你的图和需求、把理解复述一遍，你点头才动手——改方向最便宜的时刻 |
| **会认任务** | 自动区分八类需求：照片修图 / 创意合成 / 平面设计 / 切图导资产 / 批量处理 / 绘画辅助 / AI 生成 / 以及"这事不该用 Photoshop 做"（会直接指路该用什么工具） |
| **会积累经验** | 每完成一个真实任务，把验证有效的做法沉淀进"经验库"，同类任务下次直接调用（经验库刚起步，随着你的任务成长） |
| **可选本地 AI** | 可接入你自己电脑上的 LM Studio（本地模型）用于内部挑选经验条目——数据不出本机；不接也完全能跑 |
| **自带体检** | 一条命令自检环境是否正常（连接、版本、核心工具），绿灯了再开工 |

## 快速开始

1. 把这个文件夹放好，对你的 AI 助手说：**"读 SKILL.md，按它操作。"**
2. 先做环境体检（会顺便帮你启动 Photoshop）：

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts/ps_connect.ps1
   ```

   看到 `OK-CONNECT` 和版本号（如 `v=27.10`）就是通了。

3. 给助手**文件路径 + 想要的效果**（例："把这张图的白色网格去掉"、"这批图统一调个色"），
   剩下的按手册走。

## 环境要求

- Windows
- Adobe Photoshop（在 **2026 版 27.10** 上完整实测；其他版本可用，但手册里每条结论都
  标了"实测过 / 查资料 / 待验证"，换版本时会告诉你哪些要重新确认）
- **不需要**：插件、UXP 开发者工具、Python 以外的任何依赖（脚本只用系统自带能力）

---

## 隐私

- 全部在本机运行，不收集、不上传任何数据
- 仓库不含任何个人信息；示例中的个人路径均已脱敏
- 可选功能（本地 AI）只连接你自己电脑上的本地服务

## 给想改它的人

| 目录 | 是什么 |
|---|---|
| `SKILL.md` | 操作手册主入口（怎么连、怎么保安全、什么任务走什么流程） |
| `references/` | 分册：任务问询、连接与故障处理、图层与色彩机制、导出交付、经验库 |
| `scripts/` | 工具脚本：环境体检、文档盘点、任务模板、本地模型调用 |
| `docs/` | 实测记录、决策记录、案例复盘（含一个完整修图案例的全过程） |
| `evals/` | 发版前的自检脚本：`py evals/run-regression-checks.py` 一条命令自检 |

所有事实结论都带可信度标注（实测 / 资料 / 待验证），第一次实际验证后必须回写更新。
